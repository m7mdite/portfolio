# Portfolio — محمد صادق جمعة عوض

موقع شخصي عربي RTL مبني باستخدام React + Vite، مع صفحات تفاصيل للمشاريع وحركات خفيفة باستخدام Framer Motion.

## التشغيل محلياً

يتطلب Node.js 18 أو أحدث.

```bash
npm install
npm run dev
```

افتح عنوان localhost الذي يعرضه Vite في الطرفية.

## بناء نسخة الإنتاج

```bash
npm run build
npm run preview
```

ناتج البناء داخل `dist/`.

## أين أعدّل المعلومات؟

كل البيانات القابلة للتعديل تقريباً موجودة في:
`src/data/portfolio.config.js`

- `personal`: الاسم، التخصص، النبذة، المكان، البريد، الهاتف وروابط التواصل.
- `about`: النبذة والتعليم.
- `skills`: مجموعات المهارات.
- `projects`: المشاريع ووصفها وميزاتها وتقنياتها وصورها وروابطها وترتيبها.
- `settings`: اسم الموقع واللون المميز والنص السفلي.

### إضافة مشروع

أضف كائناً جديداً داخل `projects` مع `id` فريد باللغة الإنجليزية، ثم أضف الصور إلى مجلد جديد تحت `public/images/projects/<id>/`. استخدم `featured: true` ليظهر ضمن المشاريع الثلاثة المختارة. زر «عرض جميع المشاريع» يكشف باقي المشاريع تلقائياً. صفحة التفاصيل تعمل على المسار `/projects/<id>`.

الترتيب بحسب `order`. لتغيير الترتيب، عدّل أرقام `order`. لإخفاء مشروع احذفه من مصفوفة `projects`.

## الصور

راجع `public/images/README.txt` لمعرفة أسماء الملفات المقترحة وعدد اللقطات لكل مشروع. إذا لم تتوفر الصورة، سيظهر بديل واضح ولن يتعطل الموقع. لا توجد صور مزيفة للمشاريع مضمّنة.

## السيرة الذاتية

ضع ملفك في `public/files/resume.pdf` إذا أردت إضافة رابط تحميل. الملف غير موجود ضمن هذه الحزمة.

## الروابط

روابط التواصل موجودة في `personal`. اترك قيمة `linkedin` فارغة إلى أن يتوفر رابطك الحقيقي. روابط GitHub للمشاريع غير مضبوطة لأن رابط المستودع المذكور في المعلومات يبدو غير صالح؛ أضف الرابط الصحيح في المشروع المعني عندما يتوفر.

## ملاحظات محتوى

- لم أدرج تاريخ الميلاد لأنه ورد كـ 1/1/2022، وهو غير متوافق ظاهرياً مع التخرج في 2026؛ صححه في الملف إذا أردت عرضه.
- لم أضع ادعاءات عن عدد سنوات الخبرة أو مستوى إتقان رقمي.
- الخطوط من Google Fonts مع بدائل نظامية؛ إذا أردت تشغيل الموقع دون اتصال، يمكن استضافة ملفات الخط محلياً.
- نموذج التواصل غير موجود؛ زر البريد يفتح تطبيق البريد باستخدام `mailto:`.
- لم يتم تضمين صور حقيقية أو بيانات حساسة للمرضى.

## ما تم التحقق منه

تم إنشاء هيكل المشروع والملفات وربط المكونات وملف البيانات. لم يتم تشغيل `npm install` أو `npm run build` في بيئة الإنشاء، لذلك لم أدّعِ نجاح فحص بناء فعلي.
